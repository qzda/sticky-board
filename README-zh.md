# [Sticky Board](https://sticky-web.netlify.app/)

![Sticky Board Demo](./public/demo.png)

[English](./README.md) | [中文](./README-zh.md)

一个简洁优雅的网页便签板，支持拖拽操作、网格对齐和 Markdown 语法。

所有数据仅保存在本地，无需账号，无需同步，打开即用。

## ✨ 特性

- 🔒 **本地存储** – 所有数据仅存储在浏览器中
- 📄 **Markdown** – 支持使用 Markdown 语法编写内容并预览
- ⌨️ **快捷编辑** – 右键卡片进入编辑，点击空白处或按 Esc 回到预览
- ✏️ **编辑/预览切换** – 顶栏按钮一键在编辑与预览之间切换
- 📋 **一键复制代码** – 预览中的代码块右上角提供复制按钮
- 🖼️ **粘贴图片** – 支持从剪贴板粘贴图片到 Markdown（单张限制 20MB）
- 📐 **网格对齐** – 移动卡片或调整大小自动吸附到网格
- 🗖 **最大化便签** – 单张便签铺满视口，一键还原原来的位置与大小
- 🗓️ **时间轴布局** – 按日期分组，以时间轴形式展示便签
- 💾 **自动保存** – 所有修改都会自动保存
- 📤 **导入/导出** – 便签与粘贴图片打包为 ZIP（Markdown + 图片 + 配置）
- 🌤️ **Sunny 主题** – 可选的动态树叶光影覆盖层
- 🌓 **深色模式** – 自动跟随系统主题
- 🌍 **多语言** – 根据浏览器语言自动切换中英文
